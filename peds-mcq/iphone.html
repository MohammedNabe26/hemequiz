Peds MCQ — iPhone

1. Install the app Open the app
  1. Open this page in Safari.
  2. Open the app → Share ⬆️ → Add to Home Screen.
  3. Open Peds MCQ from the Home Screen and choose the file peds-mcq-data.json once.
2. Notifications every 30 min
  1. In the app (opened from the Home Screen): Set up notifications → Enable notifications → Allow.
  2. Copy CONFIG and save it on GitHub as a secret named PEDS_CONFIG (friend: PEDS_CONFIG_2).
  3. Tapping a notification opens the app on that question, with your progress.

If you added the old “Peds MCQ” calendar, delete it: Settings → Calendar → Accounts → Subscribed Calendars → Peds MCQ → Delete Account.
