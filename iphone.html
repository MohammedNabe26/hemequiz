HemeQuiz on iPhone

1,090 hematology questions from 35 chapters, with the original tables and hourly questions. You need iOS 16.4 or newer.

1. Install the app

Open this page in Safari. Chrome on iPhone can't install apps or receive notifications.

Open HemeQuiz
  1. In Safari tap Share ⬆️ → Add to Home Screen → Add.
  2. Close Safari and open HemeQuiz from your Home Screen. Always use this icon, because the progress, tables and notifications belong to it.

2. Table pictures (once)

  1. Save hemequiz-tables.json to the Files app (tap the file → Share → Save to Files).
  2. In HemeQuiz: Settings → Table images → Import tables file → pick it from Files.
  3. Wait for "186 tables imported ✓".

3. Hourly questions

  1. In HemeQuiz (opened from the Home Screen): Settings. Set the first and last notification times → Save.
  2. Tap 1. Generate keys → 2. Enable notifications → Allow.
  3. Tap 3. Copy CONFIG.
  4. Open the GitHub link below. Name: HEMEQUIZ_CONFIG_2. Secret: paste. Tap Add secret.
Add the secret on GitHub
  1. Test it: open the link below and tap Run workflow. A question should arrive within a minute.
Send a test question

If nothing arrives: iPhone Settings → Notifications → HemeQuiz → Allow Notifications, and make sure a Focus mode isn't silencing it.
